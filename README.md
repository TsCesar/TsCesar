👨‍💻 About me

<img align="right" width="330" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="Developer coding animation">

I'm a Junior Software Developer from León, Spain, and a qualified Higher Technician in Multiplatform Application Development (DAM).

I currently work at Proconsi, supporting enterprise software and working every day with business applications, databases and real technical issues.

⚙️ What I do professionally

🔧 Technical troubleshooting and application support

🗄️ SQL and DBF / XBase databases

📝 SQL and data-processing scripts

🔄 Data insertion, correction and validation

🧩 Application and data issue diagnosis

👥 User and customer support

🧱 Legacy environments: XBase · FoxPro · Clipper

My main development focus is backend engineering with Java and Kotlin, while I continue growing across web, Android, DevOps, game development and blockchain.

I enjoy understanding software beyond the interface: logic · architecture · databases · APIs · testing · deployment.
